# v1.1.0 Common Rat

**Purpose:** post-v1 hardening patch for the 1.1 Common Rat line.

This is the **v1.1.0 Common Rat** Named patch. Its purpose is to finish the post-v1 hardening work for the 1.1 line and publish the security and correctness fixes that were held in the untagged draft release.

## Highlights

- Finding evidence is verified by file and line.
- Analyzer subprocesses run with a scrubbed environment.
- The PR summary comment uses a PR-stable marker and is updated in place.
- Whole-repository audit and sprint scans no longer inherit the PR file cap.
- Python compile failures carry file and line evidence.
- Archived run JSON uses consistent field names.
- `--dry-run` no longer writes tracking state.
- Reasoning-model support includes `maxReasoningTokens` and an option to omit `response_format`.
- A configured GitHub token is respected by `run`, `finalize`, and `issue`.

## Known issues

- Provider retry is not included.
- Comment upsert calls `GET /user`; the default-token path is completed in `v1.2.0`.
- The CLI version string is hard-coded as `0.1.0`.
- The README documents a missing `--static` flag.
- The committed local `revu.yaml` is not a consumer configuration.
- GitHub Enterprise permalinks are not supported.
- Issue evidence remains reviewable, not proof.

## Verification

- CI was green at the release commit.
- Release commit: `30e90d550f0fab6e0c3e05a95e4a98b08838af31`.
