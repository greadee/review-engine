C-14.

## Sprint goal

Harden the review-critical CLI and static-analysis paths, make malformed or
hostile model output safe, remove consistency debt, gate known vulnerability
classes in CI, and publish the residual-risk register.

## Sequencing

1. **CLI and analyzer correctness:** C-09, C-10.
2. **Response safety and consistency:** C-11, C-12.
3. **Security CI and disclosure:** C-13, C-14.
4. **Sprint B review:** verify every child issue, the residual-risk register, and
   the release evidence.

## Definition of done

- All C-09 through C-14 issues are implemented and verified.
- `gofmt`, `go vet`, `go test ./...`, corpus evaluation, and workflow linting are
  green.
- Security CI is release-blocking.
- The residual-risk register is published and linked from the README.
- Sprint B is rebased onto `main` after Sprint A merges, so Sprint A's merge
  commit is not duplicated in Sprint B's work history.

## Release gate

Sprint B must not merge before Sprint A (#29). This branch and PR exist to track
the split early; implementation and final review begin after Sprint A is green
and merged.
