# Evaluation reports

This directory holds publishable evaluation evidence for a release. Reports are
generated by the CLI, not written by hand:

```bash
revu eval \
  --corpus testdata/corpus \
  --provider openai-compatible \
  --model 'deepseek v4.1 flash 1017' \
  --input-cost-per-mtok <input-price> \
  --output-cost-per-mtok <output-price> \
  --out docs/evaluation/1.3.0-narwhal.md
```

The report records the provider, the model identifier returned by the provider,
temperature, reasoning and batching limits, precision, recall, P0/P1 recall,
severity accuracy, false positives, invalid evidence, coverage, per-fixture
latency, token usage, and optional estimated cost.

Rules:

- Do not publish placeholder metrics.
- Keep the hermetic oracle result in CI; the pinned-model report is a separate,
  budgeted release artifact.
- Record the exact model identifier and settings used for the run.
- Treat the report as a snapshot for that model and corpus, not a guarantee.
